Antinet - Installation Guide
========================================

Quick Start:
  Double-click "start.bat"

Services:
  - Frontend:  http://localhost:3000
  - Backend:   http://localhost:8000
  - Genie:     http://localhost:8910  (AI Engine)
  - Hermes:    http://localhost:18119  (WebSocket)

Stop:
  Close all command windows

Directory:
  dist_package\
  - backend\         Backend code
  - venv_arm64\      Python environment
  - static\           Frontend files
  - hermes_ws_server.py
  - services\         AI models (if included)
  - start.bat         Startup script
